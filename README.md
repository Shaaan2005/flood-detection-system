# Smart Flood Detection System

This project is designed to detect rising water levels and provide alerts in case of potential flooding.

## Technologies Used
- Python
- Sensors (concept-based)
- Basic API (FastAPI)

## Working
The system monitors water levels using sensors. When the water level crosses a threshold, an alert is generated.

## Purpose
To help in early detection of floods and reduce damage.

## Configuration
API credentials are read from environment variables, never from the code. Copy `.env.example`, fill in your own Twitter/X and Telegram values, and export them before running `python main.py`. Local runtime files (`*.db`, `*.log`, `__pycache__/`) are git-ignored.
